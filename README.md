# Espresso Analysis

> An application for recording and analyzing espresso shots.

## Description

**Espresso Analysis** is a machine-learning-assisted application for recording
and evaluating espresso shots made with the Varia AKU Mini scale. It stores shot
data and uses a 1D CNN model to analyze extraction and predict shot quality.

It was built for a Gaggia Classic Pro E24 espresso machine, but it can be used
with any espresso machine as long as the Varia AKU Mini scale is available to
record shot data.

## Usage

1. Run the `manager.py` script. The application has a default idle screen, 
   press `Enter` to continue.
2. Follow the prompts to record and analyze your espresso shots.
3. Enter shot parameters and capture data from the Varia AKU Mini scale.
4. Review the analysis generated by the built-in 1D CNN model.

The CNN requires a minimum of 15 shots to train:

- 5 balanced shots
- 5 under-extracted shots
- 5 over-extracted shots

Once trained, the model can predict shot quality based on new shot data. It is
retrained whenever a new shot is added to the database.

## Note

This application was developed for personal use and may not be suitable for all
users. Additionally, the visuals were curated for a
[1993 RCA X20101GS TV](https://newspapers.digitalnc.org/lccn/sn92068245/1993-08-25/ed-1/seq-12/),
a vintage 20" CRT television. The visuals may not display correctly on modern
monitors.
